# 현재 맵 구성 현황 및 공간별 발전 제안서

## 1. 문서 목적

이 문서는 현재 프로젝트에 구현된 월드 구조를 실제 코드와 맵 에셋을 기준으로 정리하고, 각 맵이 서비스 안에서 어떤 역할을 맡고 있는지 설명하기 위해 작성되었다.

특히 다음 세 가지를 구분한다.

- **현재 플레이 가능한 기능**
- **맵과 이동 구조만 준비된 기능**
- **소개 화면에는 있으나 실제 체험으로는 아직 구현되지 않은 기능**

현재 프로젝트에는 총 8개의 맵 ID가 등록되어 있다. 그러나 모든 맵이 같은 수준으로 구현된 것은 아니다. 4개 맵은 독립 3D 월드이며, 나머지 4개 맵은 Phaser로 만든 2D 임시 공간이다.

## 2. 전체 월드 구조

### 현재 연결된 핵심 동선

```text
                         ┌──────────────┐
                         │  공동캠퍼스   │
                         │  3D 독립 맵  │
                         └──────┬───────┘
                                │ 포탈
                                │
┌──────────────┐         ┌──────▼───────┐
│ 곰 놀이 공간 │◀───────▶│ 세종호수공원 │
│  3D 체험 맵  │  경유    │ 3D 중심 허브 │
└──────┬───────┘         └──────┬───────┘
       │                         │ 포탈
       │ 상호작용 진입            │
┌──────▼───────┐                 │
│ 베어트리파크 │◀────────────────┘
│  3D 지역 맵  │
└──────────────┘
```

실제 이동 관계를 정확히 표현하면 다음과 같다.

```text
세종호수공원 ⇄ 베어트리파크 ⇄ 곰 놀이 공간
      ⇅
  공동캠퍼스
```

- 세종호수공원과 베어트리파크는 포탈로 연결된다.
- 세종호수공원과 공동캠퍼스도 포탈로 연결된다.
- 베어트리파크에서 ‘곰 만나기’ 상호작용 버튼을 누르면 곰 놀이 공간으로 이동한다.
- 곰 놀이 공간에서는 상호작용 버튼으로 베어트리파크에 돌아간다.
- 포탈은 가까이에서 약 1초간 머물면 자동으로 이동한다.

### 아직 핵심 동선에 연결되지 않은 맵

```text
조치원역
세종전통시장
조치원공원
대학로
```

위 4개 공간은 맵 ID와 2D 임시 화면이 존재하고 각 화면에서 세종호수공원으로 돌아오는 출구도 있다. 그러나 현재 세종호수공원에는 이 공간들로 들어가는 포탈이나 입구가 배치되어 있지 않아 일반적인 플레이 동선에서는 접근하기 어렵다.

별도로 존재하던 미연결 `jochwon-village.glb` 3D 에셋은 저장 공간 정리를 위해 제거했다.

| 조치원공원 | 2D 임시 맵 | 정상 동선 미연결 | 플레이스홀더 | 3개 구역, 메인 복귀 |
| 대학로 | 2D 임시 맵 | 정상 동선 미연결 | 플레이스홀더 | 3개 구역, 메인 복귀 |

## 4. 맵 1 — 세종호수공원

### 현재 역할

세종호수공원은 사용자가 처음 접속하는 **메인 로비이자 전체 월드의 허브**이다. 다른 사용자를 처음 만나고, 조작법을 익히고, 다른 3D 맵으로 이동하는 출발점 역할을 한다.

### 현재 공간 구성

- 3D 맵 에셋 기반의 넓은 야외 월드
- 최초 캐릭터 등장 지점
- 맵 전체를 이동하는 충녕이 안내 NPC
- 세종호수공원 전체를 위에서 볼 수 있는 지도 표지판
- 베어트리파크 이동 포탈
- 공동캠퍼스 이동 포탈
- 다른 사용자 캐릭터와 실시간 위치 동기화

### 현재 가능한 체험

1. WASD 또는 방향키로 이동한다.
2. Shift 키를 누른 채 이동하면 달릴 수 있다.
3. 충녕이에게 가까이 가면 튜토리얼 대화를 시작할 수 있다.
4. 지도 표지판에 가까이 가면 전체 맵을 조감 시점으로 볼 수 있다.
5. 다른 접속자의 위치와 이동 상태를 실시간으로 확인한다.
6. 포탈에 접근해 베어트리파크 또는 공동캠퍼스로 이동한다.

### 충녕이 튜토리얼 내용

- 세종호수공원이 다른 사용자를 만나는 로비라는 설명
- 이동 방법과 NPC 접근 방법 안내
- 이모트와 채팅을 통한 다른 사용자와의 교류 안내
- 이후 다른 맵에서 체험 콘텐츠를 만날 수 있다는 설명

### 현재 강점

- 서비스의 첫인상을 담당하는 공간이 명확하다.
- 충녕이, 지도, 포탈이 있어 기본적인 탐색 구조가 갖춰져 있다.
- 3D 지형의 높낮이와 이동 가능 지면을 판정해 캐릭터가 실제 지형을 따라 움직인다.
- 허브에서 여러 지역으로 확장하기 좋은 구조다.

### 현재 비어 있는 부분

- 바람의 언덕, 중앙광장 등 호수공원 내부 장소별 체험이 아직 연결되어 있지 않다.
- 지도는 전체를 보여주지만 장소 이름, 현재 위치, 목적지 안내 기능은 없다.
- 충녕이 대화는 정해진 4단계 튜토리얼이며 자유로운 AI 대화는 아직 구현되어 있지 않다.
- 소개 화면의 ‘첫 만남 스탬프’와 ‘미래 세종 스탬프’는 실제 보상 시스템으로 연결되지 않았다.

### 권장 공간 분할

| 세부 구역 | 권장 역할 | 연결할 콘텐츠 |
|---|---|---|
| 입구·스폰 구역 | 온보딩 | 충녕이 튜토리얼, 조작 연습 |
| 바람의 언덕 | 짧은 협동 체험 | 바람의 합주 |
| 중앙광장 | 모임과 공동 창작 | 미래 세종 시민광장 |
| 지도 표지판 구역 | 길 찾기 | 구역명·체험 진행도·목적지 표시 |
| 포탈 구역 | 지역 이동 | 베어트리파크·공동캠퍼스·향후 조치원 권역 |

### 제안

세종호수공원은 체험을 많이 넣기보다 다음 세 역할에 집중하는 것이 적합하다.

1. **처음 만나는 곳**
2. **다른 지역으로 이동하는 곳**
3. **전체 여정을 시작하고 마무리하는 곳**

바람의 언덕에는 2~3분짜리 협동 콘텐츠를, 중앙광장에는 여러 사용자의 활동 결과가 모이는 피날레 콘텐츠를 배치하면 허브 기능과 체험 기능이 충돌하지 않는다.

## 5. 맵 2 — 베어트리파크

### 현재 역할

세종호수공원에서 이동하는 첫 번째 자연·관광 지역 맵이다. 현재는 곰 놀이 공간에 들어가기 전의 **전이 공간이자 외부 정원형 맵** 역할을 한다.

### 현재 공간 구성

- 독립 3D 베어트리파크 에셋
- 세종호수공원으로 돌아가는 포탈
- 곰 놀이 공간으로 이동하는 상호작용 지점
- 지형 충돌과 경사 이동
- 다른 사용자 실시간 표시

### 현재 가능한 체험

1. 베어트리파크 내부를 자유롭게 산책한다.
2. 다른 사용자와 같은 공간에서 만나고 채팅한다.
3. 호수공원 복귀 포탈을 이용한다.
4. 지정 지점에서 ‘곰 만나기’ 버튼을 눌러 곰 놀이 공간으로 들어간다.

### 현재 강점

- 호수공원과 다른 분위기의 자연형 3D 맵이 분리되어 있다.
- 별도의 체험 맵으로 들어가기 전 기대감을 만드는 구조다.
- 포탈과 상호작용 진입 방식을 함께 사용해 공간의 성격을 구분한다.

### 현재 비어 있는 부분

- 맵 안에서 수행할 퀴즈, 탐색, 수집 활동이 없다.
- 소개 화면에 제시된 장소 맞춤 AI 퀴즈와 스토리텔링이 아직 구현되지 않았다.
- 사용자가 왜 ‘곰 만나기’를 해야 하는지 설명하는 NPC나 퀘스트가 없다.
- 베어트리파크 완료 여부와 곰 놀이 공간의 결과가 연결되지 않는다.

### 권장 공간 분할

| 세부 구역 | 권장 역할 | 연결할 콘텐츠 |
|---|---|---|
| 입구 포탈 | 장소 소개 | 충녕이 또는 관리인 NPC |
| 산책 구역 | 탐색 | 나무·동물 흔적 수집 |
| 이야기 구역 | 지역 학습 | AI 장소 퀴즈 |
| 곰 체험 입구 | 다음 체험 안내 | 먹이·돌봄 미션 설명 |
| 복귀 포탈 | 여정 정리 | 획득 보상과 다음 목적지 안내 |

### 제안

베어트리파크는 단순 이동 통로가 아니라 ‘곰을 만나기 위한 준비 공간’으로 정의하는 것이 좋다. 산책 중 먹이 재료나 곰 돌봄 도구를 2~3개 모은 뒤 곰 놀이 공간에 입장하도록 구성하면 두 맵이 하나의 챕터로 연결된다.

## 6. 맵 3 — 곰 놀이 공간

### 현재 역할

베어트리파크에서 분리된 **소규모 체험 전용 맵**이다. 넓은 관광 맵과 체험 공간을 분리하는 현재 프로젝트의 구조를 가장 분명하게 보여준다.

### 현재 공간 구성

- 독립 3D 체험 공간
- 공간 안을 정해진 경로로 이동하는 아기 곰 캐릭터
- 아기 곰의 기본 애니메이션
- 베어트리파크로 돌아가는 상호작용 지점
- 다른 사용자 실시간 표시

### 현재 가능한 체험

- 아기 곰이 공간 안을 돌아다니는 모습을 관찰한다.
- 곰 놀이 공간을 자유롭게 이동한다.
- 버튼을 눌러 베어트리파크로 돌아간다.

### 현재 강점

- 체험 전용 인스턴스를 별도 맵으로 분리해 집중도를 높일 수 있다.
- 움직이는 비사용자 캐릭터를 추가할 수 있는 기반이 구현되어 있다.
- 향후 먹이 주기, 따라가기, 포즈 게임으로 확장하기 좋은 구조다.

### 현재 비어 있는 부분

- ‘곰 만나기’라는 버튼명과 달리 실제 먹이 주기나 돌봄 상호작용은 없다.
- 성공 조건, 제한 시간, 진행 UI, 보상이 없다.
- 소개 화면의 MediaPipe 포즈 미니게임이 아직 연결되어 있지 않다.
- 여러 사용자가 함께 곰을 돌보는 협동 규칙이 없다.

### 권장 체험 흐름

```text
베어트리파크에서 돌봄 재료 수집
          ↓
곰 놀이 공간 입장
          ↓
곰 상태 확인
          ↓
먹이 주기·놀아주기·포즈 따라 하기
          ↓
곰 친밀도 상승
          ↓
세종 체험 스탬프 획득 후 복귀
```

### 제안

첫 버전은 복잡한 육성 시스템보다 다음 세 행동만 구현하는 것이 적합하다.

- 먹이 선택하기
- 곰이 원하는 이모트 따라 하기
- 곰과 함께 기념 화면 만들기

혼자일 때는 AI 동료가 보조하고, 2인 이상일 때는 한 명이 먹이를 준비하고 다른 한 명이 곰의 포즈를 따라 하는 협동 방식으로 확장할 수 있다.

## 7. 맵 4 — 공동캠퍼스

### 현재 역할

소개 화면에서 CH.2 ‘함께 체험하는 챕터’의 무대로 정의된 **협동 콘텐츠 전용 3D 맵**이다.

### 현재 공간 구성

- 독립 3D 캠퍼스 에셋
- 세종호수공원으로 돌아가는 포탈
- 캐릭터 이동과 지형 충돌
- 다른 사용자 실시간 표시

### 현재 가능한 체험

- 캠퍼스 공간을 자유롭게 탐색한다.
- 같은 맵의 다른 사용자와 만나고 채팅한다.
- 포탈을 이용해 세종호수공원으로 돌아간다.

### 현재 강점

- 3D 공간 자체가 준비되어 있어 협동 미션을 배치할 기반이 있다.
- 호수공원과 별도 맵으로 분리되어 챕터 단위 운영이 가능하다.
- 다른 사용자 또는 AI 동료와 함께하는 콘텐츠라는 역할이 소개 화면에 명확히 제시되어 있다.

### 현재 비어 있는 부분

- 소개 화면의 물건 운반, 동시 버튼, 길 찾기 협동 퍼즐은 아직 구현되지 않았다.
- 캠퍼스 내부의 시작 지점, 미션 구역, 완료 지점이 표시되지 않는다.
- AI 동료가 실제 플레이에 등장하지 않는다.
- 보상과 다음 챕터 개방 조건이 없다.

### 권장 공간 분할

| 세부 구역 | 권장 역할 | 콘텐츠 |
|---|---|---|
| 캠퍼스 입구 | 팀 구성 | 실제 사용자 또는 AI 동료 매칭 |
| 광장 | 조작 학습 | 동시에 버튼 누르기 |
| 이동 구간 | 협력 | 함께 물건 운반하기 |
| 건물·정원 구간 | 탐색 | 역할 분담 길 찾기 |
| 출구 포탈 | 결과 확인 | 협력 점수와 스탬프 |

### 제안

공동캠퍼스는 세 개의 짧은 협동 미션이 연속되는 구조가 적합하다. 각 미션은 1분 안팎으로 만들고, 전체 챕터는 5분 이내에 끝내는 것이 좋다. 한 명이 없어도 AI 동료가 동일한 역할을 수행해야 한다.

---

## 8. 맵 5 — 조치원역

### 현재 역할

조치원 생활권으로 들어가는 관문 역할을 의도한 2D 임시 맵이다.

### 현재 화면 구성

- 안내 데스크
- 대기 공간
- 마을 이동 안내
- 세종호수공원으로 돌아가는 출구

### 현재 구현 수준

세 구역은 이름이 붙은 직사각형 오브젝트로 표현되어 있다. 캐릭터 이동과 장애물 충돌은 가능하지만, 각 구역을 클릭하거나 접근했을 때 실행되는 체험은 없다.

또한 현재 호수공원이나 다른 3D 맵에서 조치원역으로 들어가는 정상 입구가 없다.

### 제안

조치원역은 단독 체험 맵보다 **조치원 권역의 두 번째 허브**로 활용하는 편이 적합하다.

- 전통시장, 조치원공원, 대학로로 이동하는 지역 안내
- 실제 만남 장소를 정하는 집결 지점
- 기차 시간표가 아닌 세종 지역 이야기와 이동 경로 안내
- AI 장소 추천 결과를 실제 약속 동선으로 보여주는 출발점

---

## 9. 맵 6 — 세종전통시장

### 현재 역할

지역 먹거리와 상인을 주제로 하는 생활·문화 체험 공간을 의도한 2D 임시 맵이다.

### 현재 화면 구성

- 시장 천막
- 먹거리 골목
- 상인 쉼터
- 세종호수공원으로 돌아가는 출구

### 현재 구현 수준

구역 이름과 이동 공간만 있으며 상인 NPC, 구매, 수집, 퀘스트 기능은 없다. 정상 플레이 동선에서도 아직 연결되지 않았다.

### 제안

- 시장 상인의 주문을 듣고 올바른 물건 찾기
- 여러 사용자가 식재료를 나누어 찾는 협동 장보기
- 지역 먹거리 퀴즈
- 체험 완료 후 실제 주변 식당·시장 장소 추천

현재 구현된 AI 장소 추천 기능과 가장 직접적으로 연결하기 좋은 맵이다.

---

## 10. 맵 7 — 조치원공원

### 현재 역할

산책과 가벼운 만남을 위한 생활권 휴식 공간을 의도한 2D 임시 맵이다.

### 현재 화면 구성

- 산책길
- 연못
- 벤치
- 세종호수공원으로 돌아가는 출구

### 현재 구현 수준

세 구역과 장애물만 존재하며 산책 기록, 대화 이벤트, 수집 요소는 없다. 정상 입장 동선도 연결되지 않았다.

### 제안

- 2인 산책 동행 미션
- 벤치에 앉아 공통 관심사 질문 받기
- 연못 주변 사진·포즈 미션
- 짧은 휴식형 콘텐츠와 대화 유도

세종호수공원이 대형 대표 공간이라면 조치원공원은 소규모 일상 만남 공간으로 차별화하는 것이 좋다.

---

## 11. 맵 8 — 대학로

### 현재 역할

카페, 소규모 모임, 청년 커뮤니티를 위한 생활형 공간을 의도한 2D 임시 맵이다.

### 현재 화면 구성

- 카페 거리
- 소규모 광장
- 커뮤니티 공간
- 세종호수공원으로 돌아가는 출구

### 현재 구현 수준

구역명과 이동 공간만 있고 카페 입장, 모임 생성, 게시판 등의 상호작용은 없다. 정상 동선에서도 아직 연결되지 않았다.

### 제안

- 관심사 기반 번개 모임 만들기
- 오늘의 대화 주제 카드
- AI가 두 사용자에게 적합한 카페와 활동 추천
- 소규모 광장에서 그룹 모집 및 참여

현재의 프로필, 매칭 유사도, 1:1 채팅, AI 장소 추천 기능을 공간 콘텐츠로 전환하기 좋은 맵이다.

## 12. 모든 맵에 공통으로 적용되는 시스템

### 실시간 멀티유저

- 사용자는 맵별 Socket.IO 방에 입장한다.
- 같은 맵의 사용자 위치, 방향, 걷기·달리기 상태가 동기화된다.
- 맵을 이동하면 이전 방에서 나가고 새 맵 방에 입장한다.

### 커뮤니케이션

- 주변 채팅
- 다른 사용자 프로필 선택
- 프로필 기반 매칭 유사도
- 1:1 채팅 요청과 수락·거절
- 1:1 채팅 안에서 AI 장소 추천
- 선택한 만남 장소 공유

### 캐릭터 이동

- WASD와 방향키 이동
- Shift 달리기
- 3D 맵의 경사와 높이를 따라 이동
- 경사가 심하거나 이동할 수 없는 지형 판정
- 캐릭터와 충녕이의 충돌 처리

### 접근 권한

- 정식 이용자는 채팅과 사용자 상세 기능을 사용할 수 있다.
- 체험 모드에서는 채팅과 일부 사용자 기능이 잠긴다.
- 현재 코드상 체험 모드도 세종호수공원, 베어트리파크, 곰 놀이 공간, 공동캠퍼스까지 이동할 수 있다.

## 14. 권장 챕터 구성

### CH.1 — 첫 만남

- 장소: 세종호수공원
- 구성: 충녕이 튜토리얼 → 바람의 언덕 협동 → 다른 사용자와 첫 인사
- 보상: 첫 만남 스탬프

### CH.2 — 함께 해결하기

- 장소: 공동캠퍼스
- 구성: 팀 구성 → 동시 버튼 → 물건 운반 → 길 찾기
- 보상: 협력 스탬프

### CH.3 — 세종 자연 체험

- 장소: 베어트리파크 → 곰 놀이 공간
- 구성: 탐색·퀴즈 → 돌봄 재료 수집 → 곰 상호작용·포즈
- 보상: 세종 체험 스탬프

### CH.4 — 미래 세종 완성

- 장소: 세종호수공원 중앙광장
- 구성: 미래 키워드 선택 → 공동 결과 생성 → 기념 화면
- 보상: 미래 세종 스탬프와 세종 시민증

### 확장 챕터 — 조치원 생활권

- 장소: 조치원역 → 전통시장·조치원공원·대학로
- 구성: 지역 탐색 → 사용자 매칭 → 실제 만남 장소 추천
- 역할: 메타버스 경험을 실제 세종 생활권 활동으로 연결

## 15. 개발 우선순위 제안

### 1순위 — 기존 3D 맵에 체험 넣기

1. 세종호수공원 바람의 언덕
2. 세종호수공원 중앙광장
3. 공동캠퍼스 협동 미션
4. 곰 놀이 공간 돌봄 미션

새 맵을 늘리기 전에 이미 연결된 4개 3D 맵의 방문 목적을 완성하는 단계다.

### 2순위 — 진행과 보상 연결

- 퀘스트 상태 저장
- 체험 완료 판정
- 스탬프
- 챕터 잠금 해제
- 시민증

### 3순위 — 조치원 권역 연결

- 조치원역 입구 또는 포탈 추가
- 미연결 `jochwon-village.glb` 에셋 정리 완료
- 전통시장·공원·대학로의 3D 전환 또는 2D 스타일 확정
- 실제 장소 추천과 지역 맵 연결

### 4순위 — 운영 콘텐츠

- 계절 이벤트

- 사용자 생성 모임

## 16. 최종 정리

현재 월드는 다음과 같이 정리할 수 있다.

- **세종호수공원:** 사용자를 만나고 모든 여정을 연결하는 중심 허브
- **공동캠퍼스:** 협동 미션을 넣기 위한 3D 챕터 맵
- **베어트리파크:** 자연 탐색과 곰 체험을 연결하는 지역 맵
- **곰 놀이 공간:** 움직이는 아기 곰이 있는 소규모 체험 맵
- **조치원역·전통시장·조치원공원·대학로:** 구조와 명칭만 준비된 2D 확장 후보

따라서 현재 단계에서는 맵을 추가 제작하기보다, 이미 완성된 3D 공간 안에 **시작 조건·행동·성공 조건·보상**을 넣어 ‘구경하는 맵’을 ‘체험하는 맵’으로 전환하는 것이 우선이다.
