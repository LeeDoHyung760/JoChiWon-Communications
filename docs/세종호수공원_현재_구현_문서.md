# 세종호수공원 현재 구현 문서

작성 기준일: 2026-07-27

## 1. 공간 목적

세종호수공원은 사용자가 세종의 실제 공연, 먹거리·상점, 축제를 살펴보고 자신의 관심사를 저장하는 첫 번째 체험 공간이다.

저장된 관심사는 이후 베어트리파크와 수목원 체험 및 개인 맞춤형 세종 방문 코스 추천에 활용한다.

## 2. 전체 이용 흐름

현재 필수 체험 순서는 다음과 같다.

1. 세종호수공원 공용 리스폰 위치에서 시작
2. 공연 부스 체험
3. 먹거리·상점 부스 체험
4. 축제 부스 체험
5. 베어트리파크로 이동
6. 베어트리파크의 흰색 포털을 통해 수목원으로 이동

화면 왼쪽의 단계 안내판에서 현재 단계와 다음 목적지를 확인할 수 있다.

현재 단계가 아닌 부스에 접근하면 해당 창을 열지 않고 다음과 같은 안내를 표시한다.

> 공연 부스로 먼저 이동하세요!

> 먹거리·상점 부스로 먼저 이동하세요!

> 축제 부스로 먼저 이동하세요!

현재 체험해야 하는 부스의 원형 체험존만 주황색으로 강하게 빛난다. 단계를 완료하면 주황색 표시가 다음 부스로 자동 이동하며, 다른 체험존은 흰색으로 유지된다.

## 3. 시작 안내

최초 입장 시 5단계 안내창을 제공한다.

| 단계 | 내용 |
|---|---|
| 1 | 캐릭터 이동, 달리기, 점프 방법 |
| 2 | 공연 부스 이용 방법 |
| 3 | 먹거리·상점 부스 이용 방법 |
| 4 | 축제 부스 이용 방법 |
| 5 | 베어트리파크와 수목원 이동 방법 |

마지막 안내 버튼은 `공연 부스로 출발하기`이다.

기본 조작은 다음과 같다.

- 이동: `W`, `A`, `S`, `D` 또는 방향키
- 달리기: 이동 중 `Shift`
- 점프: `Space`

## 4. 체험 공간 구성

### 4.1 공연 부스

세종예술의전당의 실제 공연 포스터를 카드 형태로 제공한다.

현재 노출 공연은 다음과 같다.

- 12시 런치 콘서트
- 뮤지컬 〈서편제〉
- 연극 〈렁스〉
- 심야음악회 〈별 헤는 밤, 별 하나〉

각 카드에서 다음 정보를 확인할 수 있다.

- 공식 포스터
- 공연 제목과 분위기
- 간단한 설명
- 일정과 장소
- 공식 공연 정보 링크

사용자는 최대 2개를 선택할 수 있다. 하나 이상 선택한 뒤 `저장 완료하고 닫기`를 누르면 공연 취향이 저장되고 먹거리·상점 단계가 열린다.

### 4.2 먹거리·상점 부스

화면 이름은 `세종 맛 발견소`이며 실제 세종 먹거리와 방문 장소를 분야별로 보여준다.

분류는 다음 세 가지다.

- 지역 먹거리 TOP 6
- 카페·디저트 TOP 6
- 시장·상점 TOP 6

카드를 선택하면 대표 사진, 이름, 설명, 실제 위치, 특징 태그를 확인할 수 있다.

주요 데이터 예시는 다음과 같다.

- 지역 먹거리: 조치원 복숭아, 왕천파닭, 맛나당칼국수, 복누룽지삼계탕 등
- 카페·디저트: 바이핸커피, 수아빈, 미스터빈커피로스터스, 팡쇼과자점 등
- 시장·상점: 세종전통시장, 금남대평시장, 부강전통시장, 싱싱장터 등

선택한 항목은 화면 아래 `내가 고른 세종 맛` 영역에 표시된다. 하나 이상 고른 뒤 `저장 완료하고 닫기`를 누르면 저장 알림이 나타나고 축제 단계가 열린다.

### 4.3 축제 부스

2026년 세종의 실제·공식 축제 정보를 카드 형태로 제공한다.

현재 포함된 콘텐츠는 다음과 같다.

- 제24회 세종 조치원복숭아축제
- 2026 세종한글축제
- 2026 세종낙화축제
- 2026 조치원 봄꽃축제
- 제104회 세종 어린이날 축제
- 세종대왕 나신 날 × 세종 책사랑 축제
- 2026 세종단오제
- 2026 거리 한글문화 한마당

카드를 누르면 큰 상세 화면에서 다음 정보를 확인할 수 있다.

- 대표 이미지
- 축제 설명
- 개최 시기
- 개최 장소
- 진행 상태
- 주요 키워드와 정보 출처

하나 이상의 축제를 선택한 뒤 `저장 완료하고 닫기`를 누르면 호수공원 필수 체험이 완료된다. 기존의 `공연 부스 가기` 버튼은 제거되어 있다.

### 4.4 세종 추천 코스 게시판

필수 3단계와 별도로 실제 방문 가능한 세종 여행 코스를 확인하고 저장하는 공간이다.

현재 제공하는 코스 유형은 다음과 같다.

- 세종 도심 핵심 당일 코스
- 세종 시티투어 야경 코스
- 조치원 로컬 미식 코스
- 아이와 함께 세종 나들이

코스를 누르면 장소가 방문 순서대로 표시되며 `나도 이 코스 가고 싶어요`로 저장할 수 있다.

## 5. 저장되는 사용자 정보

브라우저에는 다음 데이터가 저장된다.

```json
{
  "savedContentIds": ["hangeul-festival"],
  "activities": ["lunch-concert"],
  "foodInterests": [],
  "shopInterests": [],
  "festivalTheme": "",
  "likedCourseTitles": [],
  "updatedAt": 0
}
```

주요 저장 항목은 다음과 같다.

| 체험 | 저장 데이터 |
|---|---|
| 공연 부스 | 선택한 공연 ID, 최대 2개 |
| 먹거리·상점 부스 | 음식 관심사와 상점 관심사 |
| 축제 부스 | 관심 축제 ID |
| 추천 코스 게시판 | 가고 싶은 코스 제목 |
| 단계 안내 | 완료한 체험 단계 |

저장 키는 다음과 같다.

- 관심사: `sejong-lake-interest-profile-v1`
- 진행 단계: `sejong-lake-journey-step-v1`

새로고침해도 선택 항목과 완료 단계가 유지되며, 마지막으로 완료한 다음 단계부터 이어서 체험한다.

현재 사용자 관심사와 진행 단계는 브라우저 `localStorage`에 저장된다. 따라서 같은 브라우저에서는 유지되지만, 로그인 계정 기반 서버 저장은 아직 적용되지 않았다.

## 6. 팝업과 캐릭터 이동

공연, 먹거리·상점, 축제 팝업이 열려 있는 동안에는 캐릭터 입력을 잠근다.

다음 동작으로 팝업을 닫으면 이동이 즉시 복구된다.

- 우측 상단 `X`
- `ESC`
- `저장 완료하고 닫기`

팝업 종료 시 남아 있는 버튼 포커스도 해제해 키보드 이동이 멈추지 않도록 처리했다.

## 7. 리스폰과 공용 위치

세종호수공원의 기본 공용 리스폰 위치는 서버의 `RoomStore`에서 관리한다.

현재 기본값은 다음과 같다.

```json
{
  "x": 1870,
  "z": 1180,
  "yaw": 2.1
}
```

클라이언트는 입장할 때 Socket.IO의 `getRespawnPosition`을 호출해 서버 위치를 받아온다.

현재 일반 클라이언트의 `saveRespawnPosition` 요청은 서버에서 거부하도록 잠겨 있다. 즉, 모든 사용자가 동일한 서버 리스폰 위치를 사용하지만 화면에서 위치를 다시 편집하는 기능은 비활성 상태다.

부스 위치는 서버의 다음 네 체험 ID로 관리한다.

- `activity-zone`: 공연 부스
- `food-shop-zone`: 먹거리·상점 부스
- `central-plaza`: 축제 부스
- `wind-hill`: 세종 추천 코스 게시판

서버가 전달한 공용 체험 위치는 접속한 모든 클라이언트에 동일하게 적용된다.

## 8. 포털과 다른 공간 연결

세종호수공원에는 베어트리파크와 공동캠퍼스 등 다른 맵으로 이동하는 포털이 있다.

필수 체험 완료 후 안내판에 `베어트리파크로 출발` 버튼이 나타난다.

권장 이동 흐름은 다음과 같다.

```text
세종호수공원
  → 베어트리파크
  → 흰색 원형 포털
  → 수목원
```

수목원에서 베어트리파크로 돌아오면 무거운 수목원 WebGL 렌더러를 즉시 제거한다. GPU 메모리와 WebGL 컨텍스트를 해제해 복귀 후 발생하던 렉을 줄였다. 수목원에 다시 입장하면 필요한 렌더러를 새로 불러온다.

## 9. 캐릭터와 지형 처리

세종호수공원은 Three.js 기반 3D 맵과 Phaser 기반 게임 입력을 함께 사용한다.

지형 이동에는 다음 안전 처리가 적용되어 있다.

- 한 번에 올라갈 수 있는 높이 제한
- 점프로 지붕을 정상 지면처럼 타고 올라가는 현상 방지
- 이미 높은 구조물에 올라간 경우 주변 지면으로 내려올 수 있는 낙차 허용
- 팝업 표시 중 게임 입력 잠금

## 10. 실시간 백엔드 기능

백엔드는 Express와 Socket.IO로 구성되어 있다.

현재 연결 기능은 다음과 같다.

- 맵별 접속 사용자 표시
- 다른 사용자의 위치와 이동 상태 동기화
- 주변 채팅
- 1:1 대화 및 그룹 기능
- 공용 포털 위치 전달
- 공용 체험 부스 위치 전달
- 공용 리스폰 위치 전달
- 체험 방문 통계
- 축제 API 제공

기본 주소는 다음과 같다.

- 프론트엔드: `http://localhost:5173`
- 백엔드: `http://localhost:3001`
- 축제 API: `GET /api/festivals`
- 실시간 통신: `/socket.io`

## 11. 축제 API

Express의 `GET /api/festivals`가 축제 정보를 제공한다.

처리 우선순위는 다음과 같다.

1. 2026 세종 공식 축제 데이터
2. 한국관광공사 TourAPI
3. 세종특별자치시 문화축제 OpenAPI

외부 API 키는 `server/.env`에서만 읽으며 프론트엔드에 노출하지 않는다.

사용 환경 변수는 다음과 같다.

- `SEJONG_API_KEY`
- `SEJONG_FESTIVAL_API_URL`
- `TOUR_API_KEY`

API 응답은 공통 `Festival` 객체로 정규화하고 시작일과 종료일을 기준으로 예정, 진행 중, 종료 상태를 계산한다. 외부 호출 결과에는 1시간 메모리 캐시를 적용한다.

## 13. 현재 구현상 주의 사항

- 개인 체험 기록은 서버 계정이 아니라 브라우저에 저장된다.
- 다른 컴퓨터나 다른 브라우저로 이동하면 개인 체험 진행 상태가 자동 공유되지 않는다.
- 공용 리스폰 위치는 서버에서 내려오지만 일반 사용자 변경은 잠겨 있다.
- 부스에 표시되는 축제 데이터는 API 구조가 준비되어 있으나, 현재 카드 화면은 `LakeParkExperiences.tsx`의 2026 데이터와 로컬 이미지를 직접 사용한다.
- 최초 안내창은 게임 화면 진입 시 다시 열리는 현재 구조이므로, 안내 완료 여부를 별도로 저장하려면 추가 작업이 필요하다.
