# Object placeholders

나무, 벤치, 가로등, 시장 천막 등 교체 가능한 게임 오브젝트를 두는 폴더입니다.

## 개인공간 코티지

- `personal-space-cottage.glb`: 외관 정원과 거실·식당·주방·침실이 함께 보이는 컷어웨이 개인공간
- `personal-space-cottage-source.blend`: 수정 가능한 Blender 원본
- `personal-space-cottage-preview.png`: 외관 확인용 렌더
- `personal-space-cottage-interior-preview.png`: 지붕·정면 외벽을 숨긴 내부 확인용 렌더
- 재생성: `blender --background --python scripts/create_personal_space.py`
- 단위: 미터, 바닥 중심 원점, 권장 캐릭터 시작점 `(0, -2.3, 0.9)`
